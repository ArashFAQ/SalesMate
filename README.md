# SalesMate Mobile v2.3.1

برنامه‌ی وب (PWA) برای گوشی؛ **هیچ چیزی در ابر نمی‌نویسد**. همه‌ی بخش‌های ویندوز به‌جز «تحلیل فروش»:
خانه، حواله‌ها، استعلام (ارسال تصویر/متن در پیام‌رسان)، موجودی، راس چک، مشتریان، اطلاعات مشتریان، گزارش‌ها،
فروشگاه، بالانس موجودی، مشتریان و محاسبات، آمار فروش پارکت، سمپل و استند، تنظیمات.

## راه‌اندازی
1. در Supabase → SQL Editor فایل `SUPABASE_MOBILE.sql` را یک‌بار Run کنید (بعد از `SUPABASE_HARDEN.sql`).
2. در برنامه‌ی ویندوز (نسخه ≥ ۱.۱۱.۲) یک‌بار «ارسال به ابر» بزنید تا آمار پارکت، سمپل/استند و بالانس به ابر بروند.
3. پوشه‌ی برنامه را روی یک هاست HTTPS (مثلاً GitHub Pages) بگذارید؛ در Chrome باز کنید → «افزودن به صفحه‌ی اصلی».
4. با همان ایمیل و رمز ویندوز وارد شوید.

## نکته‌ها
- داده‌ها در گوشی کش می‌شوند و آفلاین هم دیده می‌شوند. دکمه‌ی ⟳ بالای صفحه به‌روزرسانی می‌کند.
- برای ارسال تصویر استعلام در واتس‌اپ/تلگرام از «ارسال تصویر» (Web Share) استفاده کنید.
- فونت وزیرمتن داخل برنامه است؛ به اینترنت/CDN وابسته نیست.
- نسخه‌ی کش را در `sw.js` (`VERSION`) و پارامتر `?v=` در `index.html` با هر انتشار بالا ببرید.
